# Your media goes here

Put the files the workflows upload here: `reference.png` (the character) and `driving.mp4` (the motion or the video whose person is replaced) for
`wan22-animate.toml` and `scail2*.toml`, `start.png` for `wan22-i2v-a14b.toml`, and an optional `prompt.txt` (your prompt as plain text) for any of them.
Other names work too: change the `inputs = [...]` list in the spec. Everything in this directory except this file is ignored by git.
